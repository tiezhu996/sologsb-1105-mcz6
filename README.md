# 老地图图幅编目与地名对照台

面向古地图整理者和地方志研究者，将老地图按图幅编目，登记年代、比例尺、投影和扫描件，并建立古今地名对照及沿革线索。应用为纯前端单页程序，所有资料保存在浏览器本地。

## Docker 一键启动

```bash
cp .env.example .env && docker compose up -d --build
```

服务默认映射到宿主端口 `21805`。停止服务可执行：

```bash
docker compose down
```

## 数据存储说明

应用使用 IndexedDB 持久化数据，Dexie 数据库名为 `gboldmap-db`。数据库包含 `sheets`、`scans`、`placePairs`、`histories`、`withdrawals` 五个对象仓库：

- `version(1)` 建立首版索引结构，并在首次创建数据库时写入图幅、扫描件、地名对照和沿革种子数据。
- `version(2)` 保持现有索引并对已有图幅执行 `schemaRev = 2` 的回填迁移，用于演示后续结构升级路径。
- `version(3)` 新增 `withdrawals` 仓库（`id, sheetId, sheetCode, stage, updatedAt` 索引），保存撤编检查点与资料快照，支持写入失败后恢复、撤编后从快照撤销。

刷新或关闭页面不会丢失新增记录；浏览器站点数据被清除时会重新触发首次种子数据写入。

## 图幅撤编流程

撤编在图幅详情页办理，针对两个页签同时整理、撤编时只清掉看得见资料的问题设计：

1. **固定资料（检查点）**：打开撤编确认页时，在同一个只读事务中固定当前扫描件、地名对照、沿革清单与双向受影响邻接图，并计算逐项指纹，写入 `pinned` 检查点。
2. **并发改动提示**：固定期间另一页签新增/修改扫描件、地名、沿革或邻接关系时，通过 BroadcastChannel（旧浏览器回退 localStorage 事件）即时通知；窗口重新获得焦点时也会复检。指纹不一致即列出变动项，要求重新核对后方可确认。
3. **一次原子写入**：确认撤编在单个读写事务内重验指纹、写入图幅撤编状态、保存资料快照、摘除受影响邻接图中指向本图幅的图号。任一步失败整个事务回滚，不会留下半套撤编结果；失败原因记录在检查点上，可一键从检查点恢复。
4. **撤编后展示**：编目台与默认导出不显示已撤编图幅（编目台可勾选“显示已撤编图幅”，导出可勾选包含撤编快照）。详情页仍可查看原资料，状态置为只读，并可在“撤编快照”面板从快照撤销撤编，恢复原状态与邻接关系。

## 核心功能与路由表

| 路由 | 核心功能 |
| --- | --- |
| `/sheets` | 按年代、比例尺和状态筛选图幅（默认隐藏已撤编），内联新建图幅，整库导出（默认不含撤编） |
| `/sheets/:id` | 查看编制摘要、扫描件条目、主用件切换、图内地名检索、JSON 导出，并在详情页办理撤编或从快照撤销 |
| `/places` | 古今地名双栏对照，按类型和确定度筛选，对古名、今名、异写及图上方位反向查询并高亮 |
| `/places/:id/history` | 按年代排列沿革时间线，新增初置、改名、迁治或废置记录 |
| `/sheets/:id/neighbors` | 按四至排列邻接图幅，显示主用扫描件、缺编提示与拼合预览 |
| `/`、未匹配路径 | 自动跳转到 `/sheets` |
